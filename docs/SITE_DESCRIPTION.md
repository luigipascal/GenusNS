# GENUS//NS — site description

**GENUS//NS** is the public face of a computational music experiment operated by **Neural Syntax** and published by **0dB_Labs**.

Legal publisher: **Rondanini Publishing Ltd t/a 0dB_Labs** (Company No. 16548159, England and Wales).

It is a registry of invented musical species. Each species has a formal genome (tuning, rhythm, form, spectrum), a living interface driven by that genome, and transparent provenance of machine work and human decisions.

**Tagline:** Music for genres that do not exist yet.
