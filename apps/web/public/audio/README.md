# Listen / download audio

Published audio must be a **Genus Compose master** generated from the
species law (`{}` → `compose_instruction`), via the compiled pack
`foundry_brief.json` / `prompts.json`.

Do **not** drop:

- raw source stems / “original” material
- Foundry demos or unrelated exports
- Web Audio / sketch previews

Local convenience (dev only): `apps/web/public/audio/<id>.mp3`  
Production: Contabo volume `data/masters/<ID>.wav` or
`data/READY_FOR_DITTO/<ID>/audio/master.wav` after `genus publish genusns`.
